# 모델 카드 · D455 단일 장면 보드·포트 시험 모델

## 식별

- 모델: Ultralytics YOLO11s detection, 8개 클래스.
- 파일: `models/board-parts-prototype.pt`, 19,205,530 bytes.
- SHA-256: `a1a20ff158b87fc6efb9802c4eda25f27ee1b7b747e071cd4ed6334c0180683e`.
- 종류: `raspberry_pi_5`, `raspberry_pi_4`, `usb_stack`, `ethernet_port`,
  `gpio_header`, `micro_hdmi`, `usb_c_power`, `heatsink`.
- 학습 초기값: 기존 공식 YOLO11s checkpoint. 독립 새 구조 또는 R04 재학습 모델이 아니다.

## 데이터와 학습

보드 두 장을 촬영한 **원본 장면 1개**의 사전 주석과 합성 변형을 사용했다.
Pi 모델 이름은 보드 표시와 배치를 보고 부여한 주석이며 전문가 검수 여부는 확인되지 않았다.
train 160장(음성 15장), val 32장(음성 4장)은 동일 원본 장면에서 생성했다.
새 실물 보드나 촬영 세션을 분리한 검증이 아니다. 세부 수량과 seed는
`training/dataset-manifest.json`에 있다.

학습은 50에폭, 입력 960, batch 4, AdamW, lr0 0.001, lrf 0.05, weight decay 0.0005,
freeze 10, FP32(amp=False), seed 20260929로 수행했다. 실제 에폭별 수치는
`training/reports/results.csv`, 전체 설정은 `args.yaml`에 보존한다.

## 평가의 해석

학습 후 보존된 합성 개발셋 결과는 precision 99.77%, recall 100%, mAP50 99.50%,
mAP50–95 98.04%이다. 같은 원본 장면의 변형이 train과 val에 들어가므로
**이 값들은 일반화 성능이나 실제 카메라 정확도가 아니다.**

실제 카메라 기록은 부품 후보·좌표·속도와 기능 동작 관찰이다. 별도 실물 GT와
독립 시험셋이 없어 실제 precision/recall/AP는 계산하지 않았다.
빈 프레임과 합성 평행 이동 검사는 실행 경로 검증이며 정확도 평가를 대체하지 않는다.

## 실시간 결합

R04 improved epoch16이 저항·커패시터·IC·일반 커넥터를 추론한다. 이 추가 모델은
보드·구체적 포트·방열판을 추론한다. 모델별 클래스 ID가 달라 표시용 ID로 매핑하고
각 검출에 모델 출처를 붙인다. 두 모델을 함께 표시하며 공통으로 보정된 단일 점수가 아니다.
서로 다른 모델의 겹치는 상자는 독립적인 예측이므로 다른 장면에서 중복 후보가 생길 수 있다.

R04의 원래 dual 전처리와 가중치·고정 선택 기록을 유지한다. 해당 시점의 저항·커패시터
누락을 추가 모델이 해결한 것은 아니다. 부품 instance mask, 결함/정상 판정,
깊이 측정 또는 로봇 좌표 산출 기능은 포함하지 않는다.

## 적용 범위

현재 장면의 시험 및 데이터 수집 기준선으로 사용한다. 다른 보드·각도·배치·조명,
가림, 움직임에서의 성능은 독립적으로 검증하지 않았다. 고정 표시 기준 0.60은
현장 시험용 설정이며 독립 검증셋으로 최적화한 운용점이 아니다.

공식 Ultralytics 코드와 초기 가중치의 원래 라이선스 조건은 계속 적용된다.
이 비공개 기록에 새로운 재배포 권한을 부여하는 별도 라이선스는 추가하지 않았다.
