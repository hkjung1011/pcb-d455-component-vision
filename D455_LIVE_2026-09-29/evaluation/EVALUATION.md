# 평가와 관찰 범위

## 실제 D455 관찰

2026-09-29 14:49:30 KST의 D455 RGB 1280×800 프레임 905에서 보드 2개와
부품 후보 21개를 표시했다. `verified-live-input.png`, `verified-live.png`,
`verified-live.json`에 원본·주석 영상·좌표와 점수를 보존한다.

카메라 수신 약 14.99fps, 화면 추론 약 4.56fps, 최근 추론 지연 중앙값 약 45.78ms를
관찰했다. 화면은 최대 5fps로 제한했다. 카메라 요청 profile은 8fps이고 SDK 수신
시각으로 측정한 rate는 약 15fps였다. 속도는 이 장치·프로그램의 관찰값이다.

실물 정답 라벨이 없으므로 precision, recall, mAP는 **미측정(null)** 이다.
21개는 표시된 예측 개수이며 21개의 정답을 맞혔다는 뜻이 아니다. confidence 또한
정답일 확률로 보정된 값이 아니다.

## 기능 검증

- 동일 입력에서 기존 R04의 클래스·좌표·점수를 유지했다.
- 실제 카메라 프레임 번호 증가, 화면 창 1개, 오류 기록 없음, 모델 출처 및 개수를 확인했다.
- IC·USB·랜·GPIO·HDMI·USB-C·방열판 클릭 확대와 원본/낮은 점수 모드를 확인했다.
- 빈 프레임에서는 기본 기준 이상의 부품·보드가 없었다.
- 입력을 왼쪽으로 160px 이동했을 때 추가 모델의 상자도 이동했다. 원래 상자를 동일하게
  이동한 위치와의 최대 좌표 차이는 해당 기능 검사 입력에서 약 1.73px였다.

보존된 `functional-input.png`와 `r04-baseline.json`으로 `verify_runtime.py`를
재실행할 수 있다. 기능 검사 영상과 프레임 905의 실시간 캡처는 서로 다른 시각의
같은 물리 장면이다. 기능 검사와 합성 이동은 새 보드 일반화 시험이 아니다.
실행 환경이 바뀌면 실수 연산의 작은 차이가 생길 수 있다.

## 합성 개발셋 성적

`training/reports/training-summary.json`에 보존된 precision 99.77%, recall 100%,
mAP50 99.50%, mAP50–95 98.04%는 단일 원본 장면에서 파생된 합성 val 32장 결과다.
이 val과 train 160장은 원본을 공유한다. 개발 성적을 실물 독립 정확도로 합산하지 않는다.

## 관찰된 한계와 미완료 항목

R04 단독에서는 IC 2개만 기본 기준을 넘었고, 저항·커패시터가 누락됐다.
R04 보드 crop·90도 회전 시험에서도 안정적 개선 없이 오검출이 생겨 실시간
파이프라인에는 채택하지 않았다. 원래 R03 보드 검출기는 두 보드를 하나로 잡았다.
추가 모델은 단일 장면에 학습된 포트·방열판 후보를 보완하며 R04의 소형 부품
누락을 해결한 것이 아니다.

남은 평가는 새 물리 보드·촬영 세션·배치·조명을 분리한 수집, 검수된 실제 bbox 정답,
부품 종류별 P/R/AP와 음성 장면 오검출 측정이다. 이 자료를 이미 확보했다고 기록하지 않는다.
