# R04 데이터 독립 감사

판정: **PASS_DATA_AUDIT**. 36개 검사 통과. 기존 R03 원본과 시험 정답을 수정하지 않고 source XML·이미지 및 R04 파생 자료를 전수 대조했다.

## 원본 분할

| split | 원본 사진 | 보드 그룹 | target4 bbox |
|---|---:|---:|---:|
| train | 25 | 17 | 3307 |
| val | 9 | 6 | 1052 |
| test | 11 | 5 | 1348 |
| pi_test | 2 | 1 | 189 |

train+val에 해당하는 기존 23개 보드 그룹만 사용해 6그룹 조합 100,947개를 독립적으로 다시 계산했다. 조건을 만족한 29,385개 중 최적 그룹과 목적값 0.034397343066640246이 split.json과 일치했다. 일반 test와 Pi 그룹·원본 객체·제외 객체는 그대로이며 일반 test의 cohort 이름만 test → general_test로 바뀌었다. 이미 R03에서 살펴본 개발용 시험 자료이므로 미관측 최종 시험으로 표현하지 않는다.

## 두 학습 자료

개선 자료는 native1024 418개, context2048 126개, object-centered 424개다. unknown 영역 1,399회와 보이는 면적 50% 미만 목표 조각 2,722회는 별도 ignore sidecar에 보존했다. 기존 정답을 새 사람 라벨이나 mask로 세지 않았다.

모든 view의 crop 위치 집합을 다시 만들고 원본 crop·리사이즈·JPEG 바이트를 메모리에서 재생성해 SHA를 비교했다. 모든 학습·검증 YOLO 라벨을 원본 좌표로 역변환했으며 최대 오차는 4.162e-7 px였다. 47장 원본 이미지·XML의 SHA와 XML 객체 18,201개의 이름·좌표를 확인했다. 원본 그룹 및 정확한 이미지 SHA의 split 간 교차는 없었다. 이 검사는 보이지 않는 물리적 중복이나 미세한 유사 사진까지 배제하는 증거는 아니다.

## 샘플링과 프로토콜

양쪽 모두 17개 보드 그룹별 sampling weight 합계가 1이다. 같은 그룹 안에서는 IC 또는 connector 목표 라벨을 포함한 view의 우선순위가 1.5, 나머지는 1.0이며, 각 그룹의 우선순위 합계로 나눈 값이 실제 기록과 일치했다. 448회 복원 추출에서 각 그룹의 기대 추출 수는 약 26.35회다. 이는 그룹 선택 확률을 맞추는 규칙이며 부품별·클래스별 경사 기여도가 같다는 뜻은 아니다. 실제 sampler 실행과 loss ignore 구현은 별도 검증 대상이다.

protocol의 초기 공식 yolo11s.pt, 데이터 요약, native manifest SHA가 실제 파일과 일치했다. 두 학습 팔은 같은 원본 train/val을 사용한다. 해당 문서는 최대 20에폭·1,165회 optimizer 호출, class multiplier 1.0을 계획으로 기록하며, 이 감사가 그 실행 완료를 인증하지는 않는다.

감사 초기에 native_manifest의 상위 집계가 기존 train 27장·3,484개, val 7장·875개로 남아 있음을 발견했다. 부모 작업에서 이를 새 분할 기준으로 수정하고 protocol SHA를 갱신했다. 최종 검사에서는 25장·3,307개와 9장·1,052개로 일치했다. 원본 GT 수정은 없었다.

## 제한

- 새 val의 짧은 변 8–16 px 객체는 98/1,052개(9.32%)다. 공개 train+val의 분포를 이용한 개선이며 D455 분포 대표성을 입증하지 않는다.
- RGB 캡처·실제 카메라 calibration·신규 사람 mask를 수행하지 않았다.
- source_to_saved_scale은 명목 균일 배율이다. 반올림한 저장 가로·세로에서 정확한 x/y 배율은 약간 달라질 수 있으나 정규화 라벨과 좌표 왕복은 일치한다.
- 개선 팔은 view 구성과 ignore를 함께 바꾸므로 개별 요인의 효과를 분리한 실험은 아니다.

검사별 결과, 라벨 반복 수, 그룹별 가중치와 448회 추출의 클래스별 기대 노출 수, 파일 SHA는 `data_independent_audit.json`에 기록했다.
