# 현재 보드 학습과 보존된 비전 실험 · 2026-09-30

## 2026-09-30 · 보드 1,000장 미세조정 중간 결과

**검증 승격 조건을 통과해 후보 모델을 선택했습니다.** 동일 검증 mAP50–95 **80.41% → 81.46%**, 실제 추가 학습 **13에폭**(최대 20, 후보 best 5). 후보 개발 test는 mAP50 **84.05%**, mAP50–95 **72.43%**이며 선택 고정 후 1회 평가했습니다.

[설정·결과](BOARDS1000_FINETUNE_2026-09-30/README.md) · [선택 근거](BOARDS1000_FINETUNE_2026-09-30/evidence/selection.json) · [복원 안내](BOARDS1000_FINETUNE_2026-09-30/REPRODUCE.md) · [후보·선택 가중치 Release](https://github.com/hkjung1011/pcb-d455-component-vision/releases/tag/boards1000-finetune-2026-09-30)

재사용 개발 test의 Jetson AP50–95는 **30.44% → 19.94%**로 내려갔습니다. 이 결과는 부족한 하위 종류/장면 다양성을 보완할 다음 데이터 실험의 근거로 기록했습니다. 이미 고정한 모델 승격을 test 점수로 뒤집지는 않았습니다.

이 모델은 검증 기준으로 선택한 중간 후보이며 D455 기본 실행 모델로 배포하지 않았습니다. Nano 40장으로 반복 TX2 40장을 교체하는 데이터 보완은 별도의 다음 실험이고, 결과는 아직 확정되지 않았습니다.

데이터 1,000장과 650 / 150 / 200 분할은 [기존 기록](BOARDS1000_2026-09-30/README.md)과 같습니다. 원래 50에폭 모델과 기존 Release를 보존했습니다. 이 실험은 fresh optimizer/schedule의 미세조정이며 에폭 수만 비교하는 대조 실험이 아닙니다. test는 재사용 개발 평가이고 선택은 val에만 근거합니다. Nucleo·포트와 D455 실측은 미검증입니다.

# 지금까지 완료한 학습과 평가 · 2026-09-29

**PCB 개선 모델 평가를 끝냈고, 웨이퍼 표면 결함 모델을 새로 10에폭 학습했다.** 아래는 실제 실행 결과다.

| 항목 | PCB / 라즈베리파이 부품 | 웨이퍼 표면 결함 |
|---|---|---|
| 모델 | YOLO11s 기준·개선 2개 | YOLO11n 6종 bbox 검출 |
| 학습량 | 각각 최대20에폭, 마지막 일부 배치까지; 실제 optimizer1,165회 | 실제10에폭, optimizer1,932회 |
| 원본 라벨 | 학습3,307 / 검증1,052 / 일반시험1,348 / Pi시험189개 | 학습2,418 / 검증480 / 시험496개 |
| 시험 결과 | Pi 개선 mAP50–95@300 **42.08%**, 기준35.33% | mAP50 **73.73%**, mAP50–95 **36.42%** |
| 정답 중 찾은 수 | 개선146/189개, conf0.65·IoU0.5 | 380/496개, conf0.25·IoU0.5 |
| 시험 범위 | 학습 제외 Pi사진2장/1그룹; 이전에 살펴본 개발 holdout | 학습 제외 현미경사진287장; 물리 웨이퍼 ID 불명 |

두 과제는 데이터와 AP 계산 구현이 달라 점수로 서로 우열을 비교하지 않는다. PCB 기준·개선의 confidence도 각 검증셋에서 선택한 값이다. 웨이퍼 confidence0.25는 test 전에 고정한 설명용 값이다.

현재 약점은 PCB 커넥터(3/12개 검출)와 웨이퍼 스크래치(AP50–95 10.78%)다. 이 수치를 근거로 아직 실사용 수준이라고 판단하지 않는다.

## 데이터와 가중치는 이렇게 정했다

웨이퍼는 저자 공개 Wafer-Datas에서 증강 접미사가 없는 후보2,132장을 받았다. 같은 사진인데 라벨이 다른98장을 격리해 **2,034장·라벨3,394개**를 사용했다. 학습1,472장/검증275장/시험287장으로 유사 이미지 그룹을 분리했다. 사람의 신규 라벨링은0개이며 기존bbox를 사용했다.

웨이퍼 학습은 1024입력·batch4·FP32·AdamW(lr0=0.001), box/cls/DFL 손실 계수7.5/0.5/1.5다. 추가 클래스 가중치나 oversampling은 적용하지 않았다. 검증 AP로 best를 선택한 뒤 가중치 해시를 고정하고 시험했다. 수량·실제 반복 노출·가중치·선택 기록과 그래프를 함께 저장했다.

## 지금 가능한 것과 남은 것

공개 사진에서 PCB 부품/웨이퍼 결함 bbox를 찾는 모델이 준비됐다. **D455 실물 촬영 성능과 부품·웨이퍼 instance segmentation은 아직 검증/학습 완료가 아니다.** 웨이퍼 원자료는 논문에서 현미경 촬영으로 설명하며 D455 RGB와 같은 조건이 아니다. 모든 웨이퍼 사진에 결함 라벨이 있어 정상 제품만의 오경보율도 미검증이다.

다음 실물 단계는 D455 고정 거리·조명에서 RGB30장을 촬영해 실제로 보이는 최소 결함/부품 크기를 확인하는 것이다. 이30장은 계획량이며 이번에 확보한 사진 수가 아니다. 원본픽셀에서 구분되지 않는 결함은 학습량만 늘려 해결된다고 가정하지 않는다.
