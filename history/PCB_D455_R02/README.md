# R02 이전 실행 기록

이 경로는 과거 보고서의 링크를 보존하기 위한 기록 페이지다. R02 전체 코드·체크포인트·환경 기록은 [비공개 Release](https://github.com/hkjung1011/pcb-d455-component-vision/releases/tag/r03-2026-09-28)의 `PCB_D455_R02.zip`에 있다.

R02는 PCB-Vision source3 semantic 보조 실험이다. IC·전해 커패시터·커넥터를 대상으로 하며, 저항 포함 target4 instance mask 또는 D455 실사용 결과가 아니다. 원본 test8장 foreground mIoU60.59%를 R03 bbox/mask mAP와 직접 비교하지 않는다.
