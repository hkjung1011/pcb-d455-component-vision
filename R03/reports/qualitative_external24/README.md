# 공개 사진 24장 추론 예시

R03 학습에 쓰지 않은 Commons 사진에 검증셋에서 고정한 모델과 confidence를 적용했다. 정답 라벨과 대조한 mAP/recall 시험이 아니다. 표시된 검출 수를 정답 수나 성공률로 해석하지 않는다. 물리 보드의 독립성과 사전학습 자료 중복 여부는 미검증이다.
