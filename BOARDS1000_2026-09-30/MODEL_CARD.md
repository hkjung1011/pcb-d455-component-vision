# 모델 카드

- 과제: 이미지 안의 보드 전체 bbox 및 8종 클래스 검출. 부품/포트/instance segmentation 모델이 아닙니다.
- 모델: YOLO11s, [클래스 ID](configs/classes.json), 공식 COCO 초기화 → 실제 50에폭 → 검증 best epoch 48.
- 입력: RGB 640, 학습 FP32. 추론 예시는 conf 0.25이며 운영 임계값을 최적화하지 않았습니다.
- 개발 test: 200장, 230개 bbox, mAP50 **84.72%**, mAP50–95 **72.16%**. 선택 후 test 1회.
- 검증 best 재평가: mAP50 96.44%, mAP50–95 80.41%. 학습 중 epoch 48 기록은 80.35%로, 저장된 best 재평가와 소폭 다릅니다. 원래 두 기록을 보존합니다.
- 약점: Jetson AP50–95 **30.44%**, Pi5 **60.18%**. 클래스당 독립 그룹이 적고 출처/촬영 조건이 제한적입니다.
- 제외/미검증: STM32 Nucleo, 포트, 실제 D455 정확도, 실물·촬영 세션 독립성. 이전 실험 자료를 재사용한 개발 평가이므로 새 최종시험이 아닙니다.
