# PCB IC 공개 범위·기존 자료 검토

검토일: 2026-10-19. 대상: 이 저장소에 새로 추가하는 `research/IC_Teacher_Student/`와 루트 README의 안내 링크. 학습 완료나 기존 저장소 이력 전체의 권리 적합성을 인증하는 문서가 아니다.

## 저장소 선택

연결된 GitHub에서 기존 `hkjung1011/pcb-d455-component-vision`의 실제 visibility가 **public**임을 확인했다. 과거 README의 '비공개 기록' 문구는 현재 공개 상태를 보장하는 표현이 아니며 역사적 서술로 구분한다.

기존 저장소는 PCB 부품 검출, 보드 검출, 웨이퍼와 D455 관련 이력을 함께 보관한다. 이번 작업도 PCB IC 검출이므로 중복 새 저장소를 만들지 않고 별도 연구 하위 폴더로 추가한다. 기존 파일·모델·Release·데이터 분할과 과거 문서 내용은 변경하거나 새 방법으로 승격하지 않는다. 루트 README에는 새 연구 문서로 가는 안내만 추가한다.

공개 저장소의 기존 README와 파일 목록, 관련 학습 스크립트 및 로컬의 제한된 학습 메타데이터를 확인했다. 기존 clean/noise 인접 실험 기록은 있으나, 제안한 **고정 Teacher + 공유 Student 두 경로 + 세 보조 손실** 전체의 구현·학습·독립 평가 완료는 이번 확인 범위에서 확인되지 않았다. 로컬의 비공개 메타데이터·원문·경로·성능 수치는 이 문서에 전재하지 않는다.

## 자료의 사용 방식

| 자료 | 확인한 범위 | 이번 공개에서의 사용 |
|---|---|---|
| 사용자가 제공한 흐름도 2개 | 실제 이미지와 경로·손실명 확인 | 의미를 재구성한 새 SVG/Mermaid와 설계 문서 |
| 기존 PCB 저장소 | 공개 상태·현재 README·관련 파일/스크립트 확인 | 기존 이력과 이번 계획의 범위를 연결; 점수 재사용 없음 |
| 기존 로컬 IC 실험 | 제한된 scripts/status/recipe 메타데이터 대조 | 인접 실험과 새 전체 방법을 구분; 원문·실제 목록 미공개 |
| 선행연구 | 공식 논문 페이지·서지·일부 본문 확인 | 제목·링크·적용 범위 요약; 논문 그림과 본문 복제 없음 |
| 데이터 후보 | 대상·출처·확인 가능한 이용조건 검토 | 링크와 확인 수준만; 영상·라벨 다운로드/공개 없음 |

원본 그림은 기하학적으로 동일하게 복제한 것이 아니라, 고정 Teacher와 Student 가중치 공유 관계를 명확하게 표시한 공개용 재작성본이다. 사진·소속·개인 이름·촬영정보를 넣지 않는다.

## 신규 공개 허용 목록

- README, 연구 질문, 데이터·증강·학습·손실·실험 프로토콜, 공개 범위 문서.
- 미정 항목을 `null`로 표시한 설정 초안과 실제 행이 없는 CSV/실험 기록 양식.
- 표준 라이브러리 기반 메타데이터 검사·그룹 분할 도구와 임시 메타데이터 단위검사.
- 사진을 포함하지 않는 SVG와 Mermaid 원문.

실제 데이터·촬영물·정답 라벨·실제 manifest/분할 목록·sealed test payload·개인정보·토큰·환경파일·유료/비공개 자료·가중치·대용량 모델·학습 출력은 신규 공개에서 제외한다. Graphify의 로컬 분석 파일도 Git에서 제외한다. `.gitignore`는 보조 수단이며, 공개 전에는 **실제로 commit할 파일과 diff**를 읽고 검사해야 한다.

현재 새 문서·코드·도표에 별도의 포괄 라이선스를 부여하지 않았다. 외부 데이터와 Ultralytics 코드/모델은 각 권리자의 이용조건을 따른다. 공개 접근이 라이선스 허가를 대신하지 않는다. FPIC 등 이용조건이 미확정인 데이터는 해소 전 학습 준비 완료로 표시하지 않는다.

## 검토 범위와 남은 일

신규 공개 파일의 민감정보·절대경로·인증 패턴·바이너리/대용량 파일, Markdown 링크, JSON/XML 구조와 메타데이터 도구 동작을 검사한다. 이 검사는 기존 저장소의 모든 과거 commit·Release·데이터셋 권리를 전수 감사한 것이 아니다. 기존 공개 이력을 삭제하거나 visibility를 바꾸지 않는다.

남은 학습 작업은 데이터 권리·라벨/그룹 검수, 환경·예산 고정, 데이터 importer·augmentation·trainer·losses·evaluator 구현, 학습과 ablation, 봉인 독립 평가, 실물 검증이다. 이 저장소에 문서가 있다는 사실만으로 이 작업들이 완료됐다고 해석하지 않는다.
