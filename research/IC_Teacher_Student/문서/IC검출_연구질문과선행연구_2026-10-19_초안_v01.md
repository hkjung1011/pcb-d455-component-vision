# PCB IC 검출의 연구 질문과 선행연구

작성일: 2026-10-19 · 상태: 초안 · 학습·성능 검증: **미수행**

이 문서는 무잡음 입력과 저해상도·잡음 입력을 함께 사용하는 PCB IC 객체검출 학습의 연구 질문, 반증 조건과 참고 문헌을 정리한다. 사용자 흐름도의 `L_anchor`, `L_cons`, `L_HN` 및 공유 YOLO11s를 구현하기 위한 연구 설계이며, 성능 향상이나 신규성을 확인한 결과가 아니다. 실제 데이터·학습 결과·논문 그림은 포함하지 않는다.

## 1. 연구 설정과 비교의 경계

고정 Teacher의 파라미터를 `θ_T`, 학습 Student의 파라미터를 `θ`로 구분한다. Teacher는 train 자료로 학습한 기준 모델이며 본 학습 단계에서는 갱신하지 않는다. 공유 YOLO11s는 **Student의 무잡음 경로와 저해상도·잡음 경로가 같은 `θ`를 사용한다**는 뜻이다. 두 경로의 forward는 별도로 수행하되 Student 파라미터는 공유한다. Teacher까지 같은 학습 파라미터를 공유하는 구조로 해석하면 고정 Teacher 조건이 성립하지 않는다.

현재 기본 설정은 라벨이 있는 원본 이미지와 그 이미지에서 만든 열화 쌍을 사용하는 **지도학습 paired-view 설정**이다. 미라벨 데이터로 pseudo-label을 생성하는 반지도 객체검출과 구분한다. 고정 Teacher는 Mean Teacher나 Soft Teacher의 EMA·집계 Teacher와도 다르다. 해당 논문은 구성 요소와 비교 설계의 참고 출처이며, 같은 알고리즘을 구현했다는 근거로 쓰지 않는다.

`L_anchor`는 Teacher 기준 표현을 유지하는 프로젝트 손실의 명칭이다. detector의 anchor box를 뜻하지 않는다. 손실의 입력 feature, RoI 출처, 정규화, stop-gradient 방향 및 가중치는 구현 전에 별도 문서와 설정에 확정한다.

## 2. 연구 질문과 반증 가능한 가설

| 구분 | 연구 질문 | 검증할 가설 | 판단·반증 조건 |
|---|---|---|---|
| RQ1 / H1 | paired-view 학습과 세 보조 손실이 열화 입력의 IC 위치 검출을 개선하면서 무잡음 성능을 유지하는가? | 제안 조합은 같은 데이터·학습 예산의 사전 지정 baseline보다 열화 조건 평균 bbox AP50:95를 높이고, 무잡음 bbox AP50:95 하락을 **1.0 percentage point 이내**로 제한한다. | `ΔAP_clean ≥ −1.0 pp`와 `ΔAP_corrupt > 0`를 함께 평가한다. 둘 중 하나라도 만족하지 못하면 H1을 지지하지 않는다. 평균만으로 유의성을 단정하지 않고 seed별 값과 불확실성을 함께 보고한다. |
| RQ2 / H2 | L_anchor가 열화 학습 중 무잡음 기준 예측을 보존하는가? | 고정 Teacher의 clean sigmoid 예측을 보존하면 같은 C/H 조건에서 clean AP 저하가 줄어든다. | A on/off의 clean AP와 열화 AP를 함께 비교한다. class logits 정합만으로 box 위치나 전체 특징 보존을 보장하지 않으며 실제 bbox AP로 판정한다. |
| RQ3 / H3 | `L_HN`이 비IC 부품의 IC 오검출을 줄이는가? | `L_HN`은 사전에 정한 검출 threshold에서 FP/image를 줄인다. 이때 recall 감소 가능성을 함께 검증해야 한다. | FP/image, recall 및 precision–recall 곡선을 함께 비교한다. FP 감소와 recall 감소가 동시에 나타나면 tradeoff로 보고한다. recall 허용 감소폭은 validation에서 사전 확정할 항목이며 test 확인 후 정하지 않는다. |
| RQ4 / H4 | GT IC 영역의 특징 일관성이 열화 검출에 도움이 되는가? | 같은 Student의 clean 특징을 stop-gradient 기준으로 삼아 noisy 특징과 정합하는 L_cons가 열화 AP를 높인다. | 같은 A/H 조건에서 C on/off를 비교한다. 현재 9조건은 ROI 정합의 유무만 검증한다. 전체 feature 평균 정합보다 우수하다는 주장은 별도 global-feature 대조 실험이 있어야 가능하다. 좌표·stride 오류, 빈 ROI와 배경 포함을 검사한다. |

여기서 `pp`는 백분율 단위로 표시한 AP 값의 차이다. 예를 들어 clean AP가 80.0에서 79.0으로 바뀌면 `−1.0 pp`다. H1의 1.0 pp는 **검증할 허용 기준**이며 관찰한 성능이나 통계적 유의성 기준이 아니다.

비교 baseline, corruptions·severity 집합, 학습 예산, seed, model selection 기준과 confidence threshold를 validation 단계에서 고정한다. test는 모델·프로토콜 확정 뒤 독립 평가에 사용하며 test 결과를 본 뒤 가설이나 허용폭을 변경하지 않는다. 최종 비교는 이미지 수준 IC 존재 분류 지표와 구분되는 **bbox 위치 평가**로 수행한다.

합성 downsampling·noise 결과는 해당 변환에 대한 강건성 증거다. 실제 카메라에서 발생하는 저해상도·센서 잡음·조명 변화까지 검증한 것으로 확대하지 않는다. 실제 촬영 외부 검증은 별도 미완료 항목이다.

## 3. 선행연구 토픽과 공식 출처

확인일은 2026-10-19다. 아래 공식 페이지는 HTTP 200으로 확인했으며, FPIC와 Mask R-CNN은 저자 논문 본문도 확인했다. 초록을 그대로 옮기거나 원 논문 그림을 재배포하지 않았다.

| 토픽 | 논문·연도·공식 링크 | 이 프로젝트에서 참고할 점 | 동일시하면 안 되는 범위 |
|---|---|---|---|
| 지식 증류 | **Distilling the Knowledge in a Neural Network**, 2015. [arXiv](https://arxiv.org/abs/1503.02531) | Teacher 지식을 Student로 전달하는 기본 연구 방향 | PCB·YOLO11s·본 프로젝트의 `L_anchor` 수식을 직접 검증한 논문이 아니다. |

[CVF CVPR](https://openaccess.thecvf.com/content_cvpr_2016/html/Shrivastava_Training_Region-Based_Object_CVPR_2016_paper.html) | 다수의 쉬운 예제 속에서 어려운 예제를 온라인으로 선별 | OHEM은 negative 전용으로 한정되지 않는다. 본 프로젝트의 HN exclusion·top-k·정규화는 별도 결정이다. |

이 목록은 구성 요소를 설명하는 선별 문헌이다. 제안 조합의 모든 유사 연구를 조사한 결과가 아니므로 `최초`, `새로운 알고리즘`, `기존 방법보다 우수`라는 결론을 내리지 않는다. 신규성 주장을 하려면 clean/corrupt shared detector, fixed-Teacher feature distillation, consistency 및 hard-negative learning의 조합을 대상으로 추가 선행연구 대조가 필요하다.

|---|---|---|---|

IC bbox 학습 후보 | [원 논문](https://arxiv.org/abs/2202.08414) 본문에서 부품 bounding box·outline과 [Trust-Hub 배포 링크](https://www.trust-hub.org/#/data/pcb-images)를 확인했다. | Trust-Hub 직접 확인은 TLS 인증서 검증 실패로 미완료다. IC 부품 bbox 데이터가 아니다. | [공식 저장소](https://github.com/tangsanli5201/DeepPCB) README는 1,500개 template/tested image pair와 6개 결함을 명시한다. [LICENSE](https://github.com/tangsanli5201/DeepPCB/blob/master/LICENSE)에서 MIT를 확인했다. | 모든 원 이미지 권리 범위의 별도 법률 검증은 미완료다. 현재 IC 학습 기본 데이터로 채택하지 않으며 링크만 제공한다. 결함검출 확장 시에도 template/tested pair와 동일 보드 crop의 분할 누출을 점검해야 한다. |

위의 데이터 확인은 논문·README·라이선스 설명 범위다. 데이터셋 이미지, 라벨, test split이나 대용량 모델 파일을 열람·다운로드하지 않았으며 실제 클래스 매핑·품질·중복·분할 상태도 아직 검증하지 않았다.
