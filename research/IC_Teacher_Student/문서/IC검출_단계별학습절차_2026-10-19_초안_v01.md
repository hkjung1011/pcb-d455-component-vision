이 문서는 구현 순서와 완료 조건을 정의한다. 현재 실행 가능한 것은 메타데이터 분할 도구뿐이다. 기존 저장소의 검출 학습기와 새 Teacher–Student 학습기를 동일시하지 않는다.

## 학습기의 최소 계약

Teacher와 Student는 YOLO11s 구조와 IC class 순서를 맞춘다. Teacher를 공식 COCO checkpoint 그대로 쓰면 PCB IC의 기준 예측이 아니므로, 단계 2에서 IC train-clean으로 적합하거나 IC 학습 provenance가 확인된 checkpoint를 사용한다. test에 접근했거나 train provenance를 모르는 checkpoint를 독립 시험의 출발점으로 삼지 않는다.

Student를 초기화한 θ₀와 Teacher θ₀를 함께 기록한다. seed 반복의 주 분석은 고정 θ₀에서 Student seed `[17,29,43]`를 바꾸는 조건부 반복이다. 각 seed 내 모든 paired arm은 같은 초기 checkpoint를 쓴다. Teacher 학습 seed까지 반복하는 실험은 추가 비용을 포함한 별도 연구로 기록한다.

공유 Student의 BatchNorm 정책도 설정으로 고정한다. v01 초안은 paired 학습 전 구간에서 Student BN running statistics와 affine parameter를 고정해 clean/noisy 호출 순서로 통계가 달라지는 혼란을 줄이는 것이다. B0와 paired 대조군 모두 같은 정책을 적용한다. BN을 갱신하는 변형은 별도 ablation이다. eval/no_grad Teacher와 L_cons의 clean stop-gradient는 서로 다른 기능이다.

학습 재현성에는 Python·NumPy·torch seed, sampler, DataLoader worker, deterministic backend, AMP와 gradient accumulation까지 포함한다. 정밀도·배치·scheduler·optimizer update 수는 현재 설정의 `null`을 실제 환경에서 결정해 동결한다. 임의의 학습 성공 예시나 미검증 설치 명령으로 이를 대체하지 않는다.

## 구현 모듈과 검증할 항목

- `dataset_adapter`: 출처별 라벨 변환, IC 매핑, 누락 검수 상태, ignore mask, 원본↔canvas affine, 그룹 보존.
- `paired_augment`: RGB 범위·seed별 결과·동일 geometry, identity 조건, sigma 단위, golden output.
- `teacher_student_trainer`: 동일 Student 가중치 참조·fixed Teacher·BN 정책·optimizer step·checkpoint resume.
- `losses`: [정의 문서](IC검출_손실함수와구현할일_2026-10-19_초안_v01.md)의 마스크와 정규화, 각 손실 켰다/껐다의 gradient 검사. 단순 숫자 출력만으로 효과를 주장하지 않는다.
- `evaluate`: 원본 좌표로 복원, pre/post NMS 구분, AP evaluator 설정, 일대일 매칭, max_det, 빈 GT 영상, group bootstrap.

각 모듈은 위 계약에 필요한 작은 단위검사와 소량의 **train/val 전용** end-to-end smoke test를 통과해야 한다. smoke test는 ablation 성능이나 학습 완료가 아니다. 실제 데이터·모델을 공개 저장소에 넣지 않고도 코드를 검사할 수 있도록 데이터 접근과 실행 결과를 분리한다.

## 재시작·선택·기록

실험마다 [기록 양식](../templates/IC검출_실험기록_2026-10-19_양식_v01.md)을 복사한다. 재시작 시 optimizer/scheduler/RNG/sampler state와 실제 update 수를 복원하고 fresh fine-tuning과 resume를 구분한다. 기존 결과 폴더는 덮어쓰지 않는다.

최대 update 예산은 동일하게 고정하고 early stopping은 v01에서 끈다. checkpoint 선택은 같은 validation 목적함수와 간격을 사용한다. 학습 예산·미정 환경이 고정되기 전에는 `training_ready=true`로 표시하지 않는다.
