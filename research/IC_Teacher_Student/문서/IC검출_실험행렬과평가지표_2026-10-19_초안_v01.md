# PCB IC ablation 실험 행렬·평가 지표

아래는 사전 실험 계획이며 모든 조건은 **NOT_RUN**이다. 빈 결과는 0점이 아니다. 세 λ의 기본값 1.0은 조정 전 초안이며 validation에서 정한 뒤 독립 평가 전에 고정한다.

## 실험 행렬

`A=L_anchor`, `C=L_cons`, `H=L_HN`. P 계열의 기본 검출 손실은 `0.5(L_det_clean + L_det_noisy)`다. B0는 `L_det_clean`만 사용한다. θ₀는 train-clean으로 학습·val 선택한 같은 Teacher checkpoint다.

| ID | Student 입력 | A | C | H | 역할 | 상태 |
|---|---|---:|---:|---:|---|---|
| B0 | clean만 | 0 | 0 | 0 | θ₀에서 같은 추가 update를 수행하는 clean 대조군 | NOT_RUN |
| P000 | clean+corrupt | 0 | 0 | 0 | paired 증강·계산 효과 | NOT_RUN |
| P100 | clean+corrupt | 1 | 0 | 0 | clean 기준 보존 항 | NOT_RUN |
| P010 | clean+corrupt | 0 | 1 | 0 | ROI 특징 일관성 항 | NOT_RUN |
| P001 | clean+corrupt | 0 | 0 | 1 | 어려운 배경 억제 항 | NOT_RUN |
| P110 | clean+corrupt | 1 | 1 | 0 | A×C 상호작용 | NOT_RUN |
| P101 | clean+corrupt | 1 | 0 | 1 | A×H 상호작용 | NOT_RUN |
| P011 | clean+corrupt | 0 | 1 | 1 | C×H 상호작용 | NOT_RUN |
| P111 | clean+corrupt | 1 | 1 | 1 | 전체 방법 | NOT_RUN |

계획 seed는 `[17,29,43]`로 총 27개 Student 실행이다. 이 수량은 완료된 실행 수가 아니다. θ₀ 자체도 참고 기준으로 평가하되 추가 update가 있는 B0와 구분한다. Teacher 공통 사전학습 비용은 별도로 기록한다.

초기 checkpoint, 그룹 분할, 입력 크기, optimizer update 수, 실제 batch, scheduler, precision, BN 정책, validation 주기·선택 규칙을 맞춘다. 동일 epoch만으로 계산 예산이 같다고 주장하지 않는다. clean-only는 forward 수가 적으므로 images-seen·forward 수·wall time·VRAM을 함께 보고한다. 보조 손실이 꺼진 arm에서 불필요한 Teacher forward는 생략하고 절약된 연산도 기록한다.

v01의 BN 고정 여부는 B0에도 동일하게 적용해 paired 대비 혼란을 줄인다. 향후 compute-matched clean 두 번 입력 대조군, bbox distillation, EMA Teacher, multiscale ROI, 다른 λ·HN top-k·score threshold는 **추가 연구**이며 핵심 9조건을 대체하지 않는다.

## 평가와 선택

주 과제는 bbox 위치 검출이다. image AUROC/AP를 계산하더라도 별도 보조 지표로 기록하며 bbox AP와 같은 칸에 합치지 않는다.

| 지표 | 정의와 보고 조건 |
|---|---|
| bbox AP50:95 | IoU 0.50~0.95를 0.05 간격으로 평균, IC 단일 클래스; 값의 단위 0~1/퍼센트 명시 |
| bbox AP50 | IoU 0.50의 AP; 위 지표와 별도 보고 |
| 운영 Precision/Recall/F1 | validation에서 고정한 confidence/NMS, IoU 0.50 일대일 GT 매칭 |
| FP/image | 같은 operating point의 unmatched 검출 수 / 전체 영상 수; IC 없는 영상도 별도 집계 |
| small IC 지표 | 원본 GT의 짧은 변 `<8`, `8~<16`, `16~<32`, `>=32` px; 원본→canvas 변환을 기록, 구간별 표본 수·Recall·구간 정의에 맞는 AP |
| clean 보존 | 동일 seed·영상에서 P111−P000 및 P111−B0의 clean AP 차이, percentage points(pp) |
| 강건성 | clean 제외 8개 scale×sigma 조건의 AP 평균·최악 AP·각 조건의 clean 대비 AP 감소량 |
| 실행 비용 | 학습 시간·forward/updates·peak VRAM; 추론 p50/p95 latency와 FPS는 하드웨어·batch·warm-up·CUDA 동기화 조건 포함 |

크기별 AP에서는 비대상 GT를 단순 삭제해 큰 IC 검출을 FP로 만들지 않도록 evaluator의 ignore 규칙을 구현·고정해야 한다. COCO AP_small의 면적 기준과 위 짧은 변 구간을 혼용하지 않는다.

AP 계산은 낮은 confidence floor를 사전 고정해 전체 score 순위를 보존하고, 운영 threshold 결과와 구분한다. 이미지당 IC 수가 많으면 `max_det`가 recall을 자를 수 있으므로 train/val 밀도 분석으로 상한을 정한다. AP용 confidence floor, NMS IoU, max_det, matching·보간 방식과 evaluator 버전은 test 전에 동결한다. 현재 실제 값은 미정이다.

checkpoint 선택 초안은 **validation clean AP가 B0보다 1.0pp 이상 낮아지지 않는 후보 중 8열화 조건 평균 AP 최대**다. 이 허용폭은 검증된 사실이 아닌 사전 기준이다. B0와 각 비교 checkpoint의 대응 평가 시점을 고정하며, 동률이면 clean AP가 높은 것, 그래도 같으면 이른 update를 택한다. 적격 후보가 없으면 'clean 보존 조건 실패'로 기록하고 test를 보고 규칙을 바꾸지 않는다. HN 효과의 주 분석에는 seed별 B0 선택 checkpoint의 validation F1 최대값(동률이면 높은 threshold)에서 정한 동일 수치의 confidence와 동일 NMS IoU를 모든 arm에 적용한다. 각 모델의 validation 최적 threshold 결과는 별도 보조 분석으로 표시한다. 이 운영 목적이 실제 recall 요구와 맞는지 실행 전 확인한다.

## 가설 판정과 통계

- H1(열화 강건성과 clean 보존): P111−P000의 8조건 평균 AP paired 차이를 주 비교로 삼고 B0 대비 차이도 보고한다. 열화 AP 차이의 95% group-bootstrap CI가 0을 포함하면 개선을 확정하지 않는다. B0 대비 clean AP 차이의 95% CI 하한이 사전 허용폭 `−1.0pp` 이상인지 함께 확인한다. 둘 중 하나라도 충족하지 못하면 전체 가설을 지지하지 않는다.
- H2(L_anchor 효과): 같은 C/H 조건의 A on/off에서 clean AP 저하와 열화 AP를 비교한다. sigmoid 예측 정합이 bbox 위치 보존을 자동 보장하지 않으므로 box AP로 확인한다.
- H3(HN 효과): H가 있는/없는 같은 A,C 조합에서 FP/image가 감소하면서 Recall 저하가 사전 허용범위 안인지 비교한다. Recall 허용폭은 아직 미정이며 test 전에 확정해야 한다.
- H4(ROI 특징 일관성): 같은 A/H 조건의 C on/off에서 열화 AP를 비교한다. 현재 행렬로 확인할 수 있는 것은 ROI 정합의 유무이며, 전체 feature 평균 정합보다 우수하다는 주장에는 별도 global-feature 대조군이 필요하다.

2³ factorial의 주효과·상호작용은 추가 개발 분석으로 보고한다. 주 비교와 탐색 비교를 구분하고 많은 비교 중 최선 하나만 선택해 확증 결과로 제시하지 않는다.

seed별 값과 평균·표준편차, 같은 seed의 paired 차이를 함께 보인다. 영상/crop이 아니라 PCB 그룹을 복원추출해 **같은 그룹을 모든 arm·열화 조건에 함께 재표집**한다. 초안 bootstrap은 2,000회·seed 20261019·percentile 95% CI이며 AP를 각 재표집에서 재계산한다. 그룹을 여러 번 뽑으면 evaluator용 영상 ID를 복제 instance별로 새로 지정해 중복 키 충돌을 막는다. seed 평균의 bootstrap은 관측 seed에 조건부인 데이터 불확실성이며 seed 모집단 전체의 불확실성으로 확대하지 않는다. 소수 그룹에서는 CI가 불안정함을 명시한다.

독립 test는 모든 arm과 분석 계획을 동결한 뒤 한 번의 고정된 평가 작업으로 처리하고, 실패 재실행은 원인·동일성·실제 호출 횟수를 남긴다. test에서 본 오류로 HN 규칙·threshold·모델을 바꾸면 후속 독립 시험이 필요하다. 합성 열화 성능은 실제 카메라·현장 성능과 별도로 해석한다.
