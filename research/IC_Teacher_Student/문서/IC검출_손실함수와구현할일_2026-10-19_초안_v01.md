# IC 검출: 손실함수와 구현할 일

작성일: 2026-10-19 · 프로토콜: `pcb-ic-ts-draft-v01`

**상태: `PLANNED` · `NOT_IMPLEMENTED` · `NOT_RUN`.** 이 문서는 제공된 알고리즘 흐름도를 학습 구현에 옮기기 위한 제안 명세다. 아래 수치와 연산은 초안 기본값이며 검증하거나 조정한 결과가 아니다. 학습기, 모델 내부 출력 어댑터, 데이터 권한 및 런타임 고정이 완료되지 않아 현재 상태로 학습 재현을 주장하지 않는다. 설정의 기준 파일은 [IC 검출 프로토콜](../configs/IC검출_프로토콜_2026-10-19_초안_v01.json)이다.

## 1. 모델과 입력의 관계

검출 대상은 단일 클래스 `IC`이며, 박스 위치와 검출 점수를 출력하는 YOLO11s를 사용한다. 깨끗한 영상으로 학습한 기준 모델의 가중치를 `θ₀`로 고정하여 Teacher로 사용하고, 같은 값으로 초기화한 Student `θ` 하나를 clean 경로와 noisy 경로에서 두 번 실행한다. Teacher는 `eval()`과 `no_grad()`를 적용하고 optimizer에 포함하지 않는다. EMA 업데이트는 이 명세에 포함하지 않는다.

원본 영상 `x`와 정답 박스 `y`에 같은 기하 변환 `g`를 적용해 `x_c = g(x)`, `y_c = g(y)`를 만든다. clean 입력은 잡음과 해상도 저하를 추가하지 않은 입력을 뜻하며, 촬영 원본에 잡음이 전혀 없다는 뜻은 아니다. 두 경로의 기준 canvas는 640×640이다. v0에서는 crop·flip·mosaic·mixup을 끄고, letterbox의 여백은 RGB `(114,114,114)`로 설정한다.

noisy 입력 `x_n`은 `x_c`를 축소한 뒤 같은 640×640으로 복원하고 Gaussian 잡음을 추가한 값이다. 축소·확대 모두 `torch.nn.functional.interpolate`의 `bilinear`, `antialias=True`, `align_corners=False`를 사용한다. RGB `float32`의 `[0,1]` 값에서 연산하고, 잡음을 더한 뒤 `[0,1]`로 clip한다. 축소 비율 `{1.0, 0.5, 0.25}`와 표준편차 `{0, 0.02, 0.05}`의 Cartesian product 9조건을 학습 시 균등 추출한다. `(1.0, 0)`도 포함되므로 noisy 경로가 항상 손상된 입력인 것은 아니다. 좌표계와 정답 박스는 두 경로에서 같다. 라이브러리 버전과 기준 출력은 구현 시 고정해야 한다.

한 optimizer step에서는 clean → noisy 순서로 Student를 실행하고 손실을 합쳐 한 번 역전파한다. 중간에 가중치를 갱신하지 않는다. 공유 BatchNorm의 running statistics와 추론 시 `eval()` 전환도 확인해야 한다.

## 2. 기호와 공통 규칙

| 기호 | 정의 |
|---|---|
| `b`, `B` | 배치 내 영상 인덱스, 배치 크기 |
| `i`, `N` | P3/P4/P5의 pre-NMS dense 검출 위치, 영상당 전체 위치 수 |
| `c`, `C` | 클래스 인덱스와 개수. v0는 `C=1` |
| `zᵀ`, `zᶜ`, `zⁿ` | Teacher-clean, Student-clean, Student-noisy의 sigmoid 적용 전 class logits |
| `pᵀ`, `pⁿ` | 각각 `sigmoid(zᵀ)`, `sigmoid(zⁿ)` |
| `Bⁿ` | Student-noisy의 decoded `xyxy` 박스. canvas 좌표로 통일 |
| `sg(·)` | stop-gradient. 값은 사용하되 해당 손실의 역전파를 차단 |
| `ℓ_BCE(z,p)` | 수치적으로 안정적인 `binary_cross_entropy_with_logits`의 원소별 값 |

YOLO11은 anchor-free 검출기다. `L_anchor`의 anchor는 clean 성능을 보존하기 위한 **고정 기준 모델**을 뜻하며 anchor box를 뜻하지 않는다. class 확률에는 sigmoid를 사용하고 softmax를 적용하지 않는다. 별도의 objectness 출력을 가정하지 않는다. class logits, decoded box, P3 특징의 실제 추출 위치와 모양은 선택한 Ultralytics 버전의 원본 코드와 대조해 어댑터로 고정해야 한다.

## 3. 기본 검출 손실

```text
L_det_clean = L_YOLO(f_θ(x_c), y_c)
L_det_noisy = L_YOLO(f_θ(x_n), y_c)
L_det_pair  = 0.5 × (L_det_clean + L_det_noisy)
```

`L_YOLO`는 고정한 Ultralytics 버전의 검출 손실과 기본 정답 할당을 사용한다. box·classification·DFL 구성과 내부 가중치는 실행 설정에 기록하고 임의로 재구현하지 않는다. 두 경로를 평균하는 계수 `0.5`는 고정한다. 실제 batch reduction과 이미지 크기 정규화가 이 정의와 일치하는지 구현 시험이 필요하다.

## 4. L_anchor: 고정 Teacher의 clean 예측 유지

동일한 clean 입력에서 Teacher와 Student의 **NMS 이전 동일 위치** class 출력을 비교한다. 구조와 입력 크기가 같으므로 P3→P4→P5, 각 레벨의 행 우선 순서로 위치를 대응시킨다. Teacher 출력의 온도는 `T=1`이며, foreground 마스크의 초안 임계값은 `τ_T=0.5`다.

```text
pᵀ_bic = sg(sigmoid(zᵀ_bic))
m_bi   = 1[max_c pᵀ_bic ≥ 0.5]
A_b    = sum_i m_bi
L_anchor,b = sum_i,c m_bi × ℓ_BCE(zᶜ_bic, pᵀ_bic) / (C × A_b), if A_b > 0
L_anchor,b = 0, if A_b = 0
L_anchor   = mean_b L_anchor,b
```

이는 Teacher가 foreground로 선택한 위치의 soft-target BCE다. background 전체를 Teacher와 맞추는 손실이나 clean 성능 보존의 보장은 아니다. Teacher의 오류도 전달될 수 있으며, Teacher가 foreground를 내지 않은 영상에는 이 손실이 작동하지 않는다. sigmoid soft-target BCE는 Teacher와 Student 예측이 같아도 Teacher 확률의 엔트로피만큼 양수일 수 있으므로 손실의 절대값이 0이어야 한다고 시험하지 않는다. 이 지점에서는 Student logit에 대한 gradient가 0인지 확인한다.

bbox distillation, background까지 포함한 distillation, EMA Teacher, 다른 온도·마스크는 핵심 구현에서 제외하고 후속 ablation으로 다룬다.

## 5. L_cons: 같은 IC의 clean/noisy ROI 특징 정합

v0는 Student의 **P3 특징 하나만** 사용한다. P3/P4/P5 중 GT 크기로 레벨을 고르는 규칙은 이후 별도 실험으로 남긴다. 모델 버전에서 P3에 해당하는 neck feature tensor의 hook 위치와 실제 공간 stride를 먼저 확인해야 한다.

배치의 유효한 IC 정답 박스마다 같은 `y_c` 좌표를 clean/noisy P3 특징에 적용한다. `ROIAlign(output_size=(7,7), spatial_scale=1/stride_P3, sampling_ratio=2, aligned=True)`를 사용하고, 7×7 공간 평균으로 채널 벡터 `h_c`, `h_n`을 얻는다. 두 경로에서 특징의 채널 수와 ROI 순서가 같아야 한다. ignore 또는 유효 면적이 없는 GT는 두 경로에서 함께 제외한다.

```text
u_r = sg(h_c,r)
v_r = h_n,r
cos_ε(u,v) = dot(u,v) / (max(||u||₂, ε) × max(||v||₂, ε)), ε = 1e−6
L_cons = mean_r [1 − cos_ε(u_r, v_r)], if valid ROI count R > 0
L_cons = 0, if R = 0
```

clean 특징의 stop-gradient는 **이 손실의 경로에만** 적용한다. clean 검출 손실과 `L_anchor`가 Student-clean에 주는 gradient는 유지한다. 0 벡터의 cosine gradient와 ROI 정렬을 구현 시험에서 확인해야 한다. `L_cons`는 sigmoid 검출 점수의 일치 손실과 다르다.

## 6. L_HN: 학습 영상의 어려운 배경 후보 억제

완전한 IC 라벨을 확인한 **train 영상**에서만 후보를 채굴한다. 라벨이 불완전하거나 확인되지 않은 영상에는 `L_HN=0`을 적용하고 제외 사유를 기록한다. 일반 검출 손실 역시 누락 라벨의 영향을 받으므로 데이터 적격성 검토가 선행되어야 한다. validation/test 예측을 학습 후보로 가져오지 않는다.

영상 `b`의 noisy pre-NMS 후보를 다음 순서로 선택한다.

1. `sg(Bⁿ)`를 canvas에 clip하고, 폭·높이가 양수인 박스만 남긴다.
2. 후보 박스가 ignore mask의 픽셀 영역과 하나라도 겹치면 제외한다. ignore 영역에는 라벨 정책에서 정한 불확실·잘림·미평가 영역을 포함한다.
3. `s_bi = sg(max_c sigmoid(zⁿ_bic)) ≥ 0.25`이며, 모든 유효 IC GT와의 `max IoU ≤ 0.1`인 후보만 남긴다. 완전한 라벨의 실제 배경 영상처럼 GT가 0개면 `max IoU=0`으로 정의한다.
4. score 내림차순으로 정렬하고 영상당 최대 100개를 선택한다. 동점은 P3→P4→P5, 행 우선 위치 순서로 결정한다. 선택·IoU·정렬에는 gradient를 전달하지 않는다.

**v0 중복 정책:** NMS·군집화·박스 중복 제거를 적용하지 않는다. 각 레벨의 각 dense 위치를 한 후보로 세며, 같은 배경에 겹친 여러 후보도 각각 top-100 예산에 포함한다. 하나의 dense 위치는 한 번만 선택한다. 이 정책은 특정 배경에 손실이 집중될 수 있으므로 NMS 후 채굴이나 영역당 상한은 후속 ablation으로 분리한다. class score가 높은 후보를 완전한 라벨과 비교해 고르는 절차이며, 라벨 정확성 없이 실제 오검출이라고 확정하지 않는다.

```text
H_b = 위 규칙으로 선택한 후보 인덱스 집합
L_HN,b = sum_(i∈H_b),c ℓ_BCE(zⁿ_bic, 0) / (C × |H_b|), if |H_b| > 0
L_HN,b = 0, if |H_b| = 0 또는 완전 라벨 확인 실패
L_HN   = mean_b L_HN,b
```

선택은 detach하지만 선택된 noisy class logits에는 gradient를 전달한다. 배경 후보에 추가 BCE를 주므로 기본 YOLO classification과 일부 기능이 겹친다. `L_HN` 감소만으로 실제 FP 감소를 주장하지 않고 독립 평가의 FP/image와 recall을 함께 확인한다.

## 7. 합손실과 가중치 갱신

```text
L_total = 0.5 × (L_det_clean + L_det_noisy)
        + λ_anchor × L_anchor
        + λ_cons   × L_cons
        + λ_HN     × L_HN

λ_anchor = λ_cons = λ_HN = 1.0  # 초안 기본값, 미조정
θ ← optimizer_step(∇_θ L_total)
θ₀는 고정
```

계수 `1.0`은 손실의 크기를 보정한 결과가 아니다. 후보 수·배치·ROI 수에 따라 각 항의 영향이 달라지므로, train 손실과 gradient 크기를 기록하고 validation에서만 조정한다. 각 손실의 ablation에서는 해당 λ만 0으로 설정하고 데이터·초기 가중치·업데이트 예산·선정 기준을 유지한다. 실제 추론에서는 학습한 Student 하나로 IC 박스와 점수를 출력한다. Teacher·ROIAlign·hard-negative 채굴·학습 손실은 추론 경로에 필요하지 않다.

| Teacher 고정 | eval/no-grad, Student를 같은 checkpoint에서 초기화 | Teacher parameter·running stats 불변, optimizer 제외 | `NOT_IMPLEMENTED` |

학습기 구현 전에는 위 조건을 작은 합성 tensor와 좌표로 시험한다. 이 시험은 손실 연산과 gradient 경로를 확인하기 위한 것이며, 실제 데이터의 성능 결과를 대신하지 않는다. 이어 소규모 train smoke test에서 finite loss·정상 gradient·checkpoint 복원을 확인한 뒤 계획한 학습을 시작한다.
