# 웨이퍼 R01 독립 데이터 감사

**PASS_INDEPENDENT_DATA_AUDIT** — 집계 검사34개 통과, 실패0개. 원본·학습 입력은 수정하지 않았다.

- 원본2,132장·bbox3,693개, 파일4,264개 SHA-256와 원격 Git blob SHA 재검증.
- 같은 픽셀에 라벨이 다른49그룹98장을 제외한2,034장·bbox3,394개를 확인.
- 모든 pHash Hamming≤4 후보1,586쌍을 다시 계산. 유지된1,533개 연결과 파일명 family·dHash 규칙으로1,481그룹 재구성. 그룹·파일/픽셀 해시·pHash 후보의 split 교차 없음.
- VOC 좌표→YOLO→좌표 최대 오차4.8e-8픽셀. 6개 정규 클래스와 모든 split의 라벨 수 확인.

| split | 이미지 | 그룹 | bbox |
|---|---:|---:|---:|
| train | 1472 | 1036 | 2418 |
| val | 275 | 222 | 480 |
| test | 287 | 223 | 496 |

실제 optimizer post-step hook, final best 검증의 추가 epoch callback을 제외하는 guard, 학습된 best SHA를 test 전에 고정하는 코드 경로를 확인했다. 학습 시작에 기록된 스크립트 SHA와 검토 파일 SHA가 같다. 실제 완료 에폭·optimizer 호출·최종 성능은 학습 완료 후 별도 확인해야 한다.

독립 감사는 첫 학습 진행 중 완료됐다. root의 원본·준비 데이터 검사가 학습 전에 수행됐다. 이 보고서를 학습 시작 전 독립 감사로 표현하지 않는다.

한계: 좌표의 VOC 1-based 규칙은 source 범위에 근거한 가정이며 원저자 확인은 아니다. 파일명·외형 그룹은 물리적 웨이퍼/lot 독립성을 증명하지 않는다. 현미경 공개 사진의 bbox 실험으로 D455 실사용이나 instance mask 성능을 검증하지 않았다.
